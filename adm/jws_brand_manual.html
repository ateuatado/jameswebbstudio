01 — Conceito da Marca

A Origem

O James Webb Space Telescope é o instrumento óptico mais avançado já construído pela humanidade. Seu espelho primário — um mosaico de segmentos hexagonais banhados a ouro — captura luz invisível a olho nu e revela o que estava escondido há bilhões de anos.

James Webb Studio nasce dessa metáfora: revelar a melhor versão do que já existe.

Não inventamos luz. Capturamos a que já estava ali — esperando ser vista.

02 — O Logotipo

Composição

O logotipo é composto por dois elementos:

1. O Símbolo — 3 hexágonos regulares em arranjo triangular (1 acima, 2 abaixo)

2. A Tipografia — "JAMES WEBB" em peso fino com tracking largo + "STUDIO" menor abaixo

⬡ ⬡ ⬡ J A M E S W E B B S T U D I O

O símbolo é intencionalmente pequeno em relação ao texto — funciona como um hallmark, um selo de joalheiro. Essa é a elegância.

Proporções

Largura de "JAMES WEBB" = ~10× a largura do símbolo Tamanho de "STUDIO" = 55% do tamanho de "JAMES WEBB" Tracking "JAMES WEBB" = +250 a +300 Tracking "STUDIO" = +500 a +600 Gap símbolo → texto = 2R Gap "JAMES WEBB" → "STUDIO" = 0.5R

03 — Construção Geométrica

Unidade Base

Toda a construção parte de uma única medida: o raio do hexágono (R).

UsoR recomendado
Logo digital (web)12px
Cartão de visita3mm
Papel timbrado A45mm
Fachada / banner20mm

Anatomia do Hexágono

___________ / \ / \ / \ | | \ / \ / \___________/
Lados6 iguais = R
Ângulo interno120°
OrientaçãoFlat-top
Largura2R
AlturaR × √3 ≈ R × 1.732
Contorno1pt (print) / 1px (digital)
PreenchimentoNenhum (outline only)

O Gap

G = R × 0.15 (15% do raio)

O gap é essencial. Sem ele, os hexágonos se fundem. Com gap, cada espelho é individual — como no telescópio real.

Distância entre centros

D = R × √3 + G D ≈ R × 1.732 + G Para R = 12px, G = 1.8px: D = 12 × 1.732 + 1.8 = 22.6px

Coordenadas dos 3 centros

Origem (0, 0) = centroide do triângulo.

HexágonoFórmula XFórmula YX (R=12px)Y (R=12px)

Hex 2 (base esq.)−D / 2+D / (2√3)−11.3+6.5

04 — Receita: Adobe Illustrator

Passo 1 — Hexágono base

Ferramenta Polígono → Raio: 12px, Lados: 6 → OK

Rotacionar: Object > Transform > Rotate: 30° (flat-top)

Preenchimento: nenhum / Contorno: #C5A059, 1pt

Passo 2 — Hex 1 (topo)

Posicionar no centro do artboard. Este é o ponto de referência.

Passo 3 — Hex 2 (base esquerda)

Duplicar Hex 1 (Ctrl+C, Ctrl+V)

Object > Transform > Move: Horizontal −11.3px, Vertical +19.5px

Passo 4 — Hex 3 (base direita)

Duplicar Hex 1 → Move: Horizontal +11.3px, Vertical +19.5px

Passo 5 — Agrupar

Selecionar 3 hexágonos → Ctrl+G (Group)

Passo 6 — Tipografia

Texto "JAMES WEBB": Inter Light 300, tracking +280, All Caps, cor #C5A059

Texto "STUDIO": mesma fonte, 55% do tamanho, tracking +550

Largura de "JAMES WEBB" = ~10× a largura do cluster

Passo 7 — Espaçamento

Gap cluster ↔ "JAMES WEBB" = 2R (24px) / Gap "JAMES WEBB" ↔ "STUDIO" = 0.5R (6px)

05 — Receita: Figma

O (Shape) → Polígono → Count: 6 → Rotation: 30°

Fill: remover → Stroke: #C5A059, 1px

Create Component (Ctrl+Alt+K) → nomear ⬡ hex-mirror

Instanciar 2x e posicionar por X/Y conforme tabela de coordenadas.

Frame (Ctrl+Alt+G) + Auto Layout vertical, gap = 2R

06 — Receita: CorelDRAW

Ferramenta Polígono → Lados: 6 → Ctrl (proporcional)

Arrange > Transformations > Rotate: 30°

Contorno: #C5A059, 0.3mm → Duplicar com Ctrl+D

Alt+F7 (Transformations) → aba Position → coordenadas exatas

12 — O que NÃO fazer

❌Adicionar estrelas, planetas, telescópios — a referência é sutil, não literal
❌Preencher os hexágonos com cor sólida — o outline é a identidade
❌Usar o logo sobre fundos coloridos — a marca vive em preto ou branco
❌Rotacionar o triângulo — a orientação (1 em cima, 2 em baixo) é fixa
❌Alterar o gap entre hexágonos — descaracteriza a forma
❌Usar fontes diferentes de Inter e EB Garamond
❌Adicionar sombras, brilhos ou efeitos 3D — o logo é flat
❌Escrever "james webb" em minúsculas — sempre UPPERCASE
